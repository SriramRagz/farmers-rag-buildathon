# Tamil Nadu Farmers AI Assistant

An AI-powered agricultural government schemes assistant built using Retrieval-Augmented Generation (RAG).

## Project Objective

Help farmers access government agricultural schemes, understand eligibility criteria, required documents and application procedures through a conversational AI interface.

## Planned Features

- Tamil and English question answering
- Government agriculture scheme document retrieval
- PDF-based knowledge base
- Eligibility and application guidance
- Source document and page references

## Technology Stack

- Python
- FastAPI
- Streamlit
- LangChain
- FAISS
- Sentence Transformers
- OpenAI API
- PyMuPDF

## Project Status

Currently under development as part of a RAG Buildathon.

## Future Scope

- Tamil voice interaction
- District-specific recommendations
- Government scheme updates
- Personalised farmer assistance
